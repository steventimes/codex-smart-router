# Changelog

All notable changes to this project are documented in this file.

## [0.2.0] - 2026-10-06

### Added

- Account/binary-scoped App Server model discovery with pagination, cache isolation, and doctor diagnostics.
- Joint model/effort candidate routing, session controls, native/private-HTTP classifiers, and safe pre-execution fallback.
- Validation-aware audit records, scope policy, anonymous export/retention, offline policy fitting, and 12-task synthetic replay.
- Dashboard evidence/coverage metrics and explicit API-versus-subscription cost semantics.

### Changed

- `auto` no longer infers a paid API destination from environment variables.
- Fixed model tables and unsupported-effort approximation are replaced by runtime catalog validation.
- Removed unsupported savings claims and public-package installation instructions for this fork.

## [0.1.0] - 2026-07-10

### Added

- Per-turn semantic model and reasoning routing for Codex CLI.
- Local loopback proxy with per-process bearer-token protection.
- Schema-validated classifier decisions, explicit route overrides, and model-catalog fallback resolution.
- Privacy-aware audit metadata and a local dashboard for usage and route distribution.
- OpenAI Responses API and native Codex classifier backends.

### Known limitations

- Codex App Server integration and model catalogs evolve independently of this project.
- Cost figures are estimates based on configured token pricing; they are not provider invoices.
